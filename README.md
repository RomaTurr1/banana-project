## 🚀 Описание функциональности

- **Поиск (`/`)**:
  - Поиск экспонатов с предзаполненной темой варианта (`cats`).
  - Фильтр по цвету с предзаполненным цветом варианта (`red`).
  - Адаптивная сетка карточек с сохранением пропорций (`aspect-ratio`) без дергания макета.
  - Ограничение пагинации до максимально доступной страницы согласно лимиту API 10 000 объектов (`maxPage`).
  - Состояния: загрузка, ошибки (включая лимит 429), пустая выдача. Заглушка для работ без оцифрованного изображения.
- **Карточка работы (`/artwork/:id`)**:
  - Просмотр крупного изображения через стандарт IIIF (`config.iiif_url`).
  - Полная метаинформация: автор, датировка, техника, отдел музея.
  - Кнопка «В выставку» с проверкой лимита (до 12 экспонатов) и статусом «Уже в выставке».
- **Моя выставка (`/expo`)**:
  - Редактирование названия выставки с сохранением в `localStorage` через `useReducer`.
  - Изменение порядка экспонатов кнопками `↑` и `↓`, удаление кнопкой «Убрать».
  - **Задача варианта №1**: Кнопка «📅 Хронологически» для упорядочивания произведений по возрастанию года создания (`date_start`).
  - Кнопка «Скопировать ссылку» (`encodeExpo`) для генерации ссылки на готовую выставку.
- **Просмотр выставки по ссылке (`/expo/view?title=...&ids=...`)**:
  - Чтение и строгая валидация параметров через `decodeExpo`.
  - Загрузка всей выставки **одним пакетным запросом** (`/artworks?ids=1,2,3`).
- **Сетевой слой и лимиты**:
  - Очередь запросов (не чаще 1 запроса в секунду).
  - In-memory кеширование ответов через `Map`.
  - Корректная обработка HTTP 429 («Слишком много запросов, подождите минуту»).
- **Деплой**:
  - Конфигурация `vercel.json` с rewrites для SPA-маршрутизации (предотвращает 404 при обновлении страниц).

## 🛠️ Запуск проекта

### Требования
- Node.js 20 LTS+
- npm

### Установка зависимостей
```bash
npm install
```

### Запуск тестов контракта (Vitest)
```bash
npm test
```

### Запуск локального сервера разработки
```bash
npm run dev
```

### Сборка для публикации (Production)
```bash
npm run build
```
